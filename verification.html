Rerun working examples

go build -o bin/localproxy .
python3 scripts/verify-docs-example.py \
  --output .local/docs-evidence/examples.json

The helper starts temporary app and Caddy processes on available high loopback ports. It verifies both certificate-chain and hostname checks using the generated CA and suffix dev.test. It checks that successful edits change running routes and that a stale revision is rejected. Its final check confirms process and temporary-directory cleanup.

Run the application suite

go test -race -count=1 ./...
go vet ./...

Put Caddy at bin/caddy to run the existing real-proxy integration test. Without it, that test skips even if Caddy exists elsewhere on PATH. The suite checks HTTP routing, Go-verified HTTPS, unknown-name fallback, upstream 404s, map precedence, conflicting edits, malformed requests, rollback, and custom listener preservation.

Reproduce the screenshots

The PNGs are captures of the actual application, not mockups. Capture uses default .test over HTTP with two fixture apps and no tailnet links. Port numbers vary. The helper opens an edit confirmation and cancels; it asserts no write requests and unchanged fixture files.

npm install --prefix .cache/browser-test --no-save playwright-core
python3 scripts/docs-demo.py --state-file .local/docs-capture-state.json

In a second terminal:

CHROMIUM_BIN=/usr/bin/chromium \
  node scripts/capture-docs.cjs --state .local/docs-capture-state.json

Stop the demo with Ctrl+C afterwards. See the capture guide for environment overrides and alternate output locations.

Build and check this site

The captioned demo recording shows search, editing, a confirmed rename, and Undo in a disposable fixture. Its capture helper checks the changed and restored domains through real Caddy requests. MP4 and WebM playback and caption loading are checked in the docs browser verifier. See media provenance and reproduction.

python3 scripts/build-docs.py
python3 scripts/serve-docs.py --port 18084
# In another terminal:
node scripts/verify-docs-site.cjs --url http://127.0.0.1:18084/

The builder uses only Python’s standard library and emits static files to .local/docs-site. It validates local HTML links, anchors, and duplicate IDs. The browser check additionally requires Chromium and playwright-core. The static artifact uses relative URLs and can be hosted under a repository subpath.

Performance measurements

The previous performance pass measured medians of three 300 ms runs on an Intel i9-13900HK with GOMAXPROCS=4, 10 routes, a warm file cache, and tailnet detection disabled.

OperationBefore → afterMeasured change
Directory GET handler337.4 → 125.4 µs2.69× faster
Directory HEAD handler321.4 → 12.4 µs25.99× faster
Editable config generation361.9 → 59.6 µs6.07× faster

These are Go microbenchmarks of control operations, not browser load times or application proxy throughput. No performance benchmark was rerun just to build these docs. Read the complete methodology and results.

GOMAXPROCS=4 go test -run '^$' \
  -bench 'Benchmark(Directory|CaddyConfig)' \
  -benchmem -benchtime=300ms -count=3
