GUIDES / DNS & HTTPS

Make .test feel local.

Understand name resolution, certificate trust, and machine setup.

Choose a local suffix

Localhost is not the only name you can use. Localproxy defaults to .test, which is reserved for testing by RFC 2606. A suffix such as dev.test works too. Set the registry’s suffix before creating routes, and configure your resolver for that suffix.

The reserved directory name is home.<suffix>. App names have one label before the suffix. The generated certificate covers that suffix and its wildcard.

Certificate compatibility

Some curl/Python clients using OpenSSL reject *.test certificates for app.test because of their wildcard hostname rules. Trusting the CA does not fix a hostname mismatch.

Use suffix dev.test and certificate *.dev.test for these clients. Update existing route domains and full project-map names to match, and configure DNS for the new suffix. Your browser must also trust the local certificate authority.

Try local HTTPS without system changes

The quickstart uses curl’s --resolve and --cacert. These choose a loopback address and CA for one command, without changing DNS or system trust. Use this path to separate routing failures from machine setup problems.

Arch / Omarchy setup

The included setup script targets Arch/Omarchy with systemd-resolved and the default .test suffix. It installs a dedicated dnsmasq service, routes ~test lookups to it, trusts this instance’s CA, and gives bin/caddy permission to bind ports 80 and 443. It is not a generic Linux or macOS installer.

For a registry using the default suffix and ports, first generate the config and provision the CA via Caddy validation:

./bin/localproxy generate
./bin/caddy validate --config .local/caddy.json
sudo bash scripts/install-system.sh "$PWD"

Read the script before running it. It expects the local CA root file to exist. It starts Caddy directly unless an existing localproxy user service is present. Its final curl HTTPS check can hit the default-suffix compatibility issue described above; the machine changes occur before that check.

The script is written for .test and its verification URL is home.test. With a different suffix, configure and verify your resolver separately. DNS-over-HTTPS in the browser may need an exception for local names. Browser-specific certificate stores may need the root imported separately.

Keep local trust local

Generated CA data lives at .local/caddy-data beside the registry. The public root is pki/authorities/local/root.crt beneath that directory. The directory also holds the CA’s private key and should remain private and untracked.

After replacing bin/caddy, reapply any file capability needed for privileged ports. Generated listeners bind to IPv4 and IPv6 loopback; upstream connections use IPv4 loopback.

Stop and remove setup

Use localproxy stop for a manually started instance. If a user service manages it, use systemctl --user disable --now localproxy.service so its restart policy does not bring it back. The repository removal guide lists DNS, trust, and capability cleanup.
