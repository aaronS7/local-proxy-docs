START HERE / Quickstart

From ports to names.

Run a complete, isolated demo before changing your machine.

1. Build the CLI

Use Linux, Go 1.24 or newer, Python 3.10 or newer, curl, and Caddy 2.11.4. Install Caddy using its official installation guide; place the executable at bin/caddy, on PATH, or set CADDY_BIN.

git clone https://github.com/aaronS7/local-proxy.git
cd local-proxy
go build -o bin/localproxy .

The repository is private; cloning requires GitHub access. Run the following commands from the repository root.

2. Run the isolated demo

python3 scripts/docs-demo.py \
  --suffix dev.test \
  --state-file .local/docs-demo.json

Keep this terminal open. The script launches two small HTTP apps, Caddy, and the editor. It chooses unused high ports, creates a temporary registry and project map, and prints a directory URL you can open directly. Press Ctrl+C to stop the processes and remove temporary files.

Open the printed directory_url. You will see app.dev.test and api.dev.test, their localhost ports, and their editing controls. Domain links require local DNS; the direct directory URL works immediately.

The demo uses .dev.test so strict OpenSSL clients can validate its wildcard certificate. The application default remains .test. See certificate compatibility.

3. Send a request through Caddy

In another terminal, read the dynamically assigned ports. --resolve directs only this curl request to loopback; it does not change your machine’s resolver.

HTTP_PORT=$(python3 -c 'import json; print(json.load(open(".local/docs-demo.json"))["ports"]["http"])')
HTTPS_PORT=$(python3 -c 'import json; print(json.load(open(".local/docs-demo.json"))["ports"]["https"])')
CA_FILE=$(python3 -c 'import json; print(json.load(open(".local/docs-demo.json"))["ca_file"])')

curl --noproxy '*' --fail \
  --resolve "app.dev.test:$HTTP_PORT:127.0.0.1" \
  "http://app.dev.test:$HTTP_PORT/"

curl --noproxy '*' --fail --cacert "$CA_FILE" \
  --resolve "app.dev.test:$HTTPS_PORT:127.0.0.1" \
  "https://app.dev.test:$HTTPS_PORT/"

Both requests reach the demo app. The HTTPS request uses the demo’s local certificate authority.

4. Make the name yours

In the directory, choose Edit next to app.dev.test, enter studio, choose Save, then confirm. The port stays the same. Use Undo to restore the previous name.

You can also rename from the CLI. Run these before the browser rename, or undo it first:

REGISTRY=$(python3 -c 'import json; print(json.load(open(".local/docs-demo.json"))["registry"])')
./bin/localproxy -config "$REGISTRY" rename app studio
./bin/localproxy -config "$REGISTRY" reload
./bin/localproxy -config "$REGISTRY" list

The listing keeps studio.dev.test after reload even though the project map still calls that port app. CLI and UI edits persist as overrides.

Next, set up a project map for your own apps and configure DNS and HTTPS for normal browser URLs.
