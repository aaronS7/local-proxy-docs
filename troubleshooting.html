PROJECT / Troubleshooting

Follow the request.

Check DNS, TLS, routing, and the editor one layer at a time.

The domain does not resolve

Registering a name does not configure your resolver. Check getent hosts app.test or the name under your chosen suffix. It must resolve to loopback for local app routes. Use the quickstart’s curl --resolve command to test routing independently. Check whether browser DNS-over-HTTPS bypasses the local resolver.

HTTPS reports a certificate error

Distinguish an untrusted issuer from a hostname mismatch. Use the instance’s generated root.crt with --cacert to test trust. If the error says app.test does not match *.test in curl/Python, use the documented .dev.test workaround. Installing the root again will not change hostname matching.

A registered app fails

Open its original http://localhost:<port> link. Confirm the app accepts IPv4 loopback connections and its port matches the registry. If it rejects the custom hostname, allow that hostname in the app or set the route’s localhost_host option and reload. App 404s and upstream failures are not replaced with the directory.

An unknown name gets 403

The editable directory restricts Host headers. Use an unregistered single-label name under your configured suffix, such as missing.dev.test, or the machine’s recognized local/Tailscale address. Arbitrary external Host headers are rejected. Static and editable fallback have different Host behavior.

Editing is missing or fails

Check that directory_address is configured, the UI process is listening at that address, and Caddy has reloaded it. The static directory has no editing controls. For an instance-specific admin port, pass --proxy-admin; use --proxy-config to retain its restart snapshot.

Refresh after a revision conflict. If Caddy rejects a browser edit, inspect its logs before retrying. If a CLI command reports a failed reload, its registry change may already be saved; correct the failure and reload. Do not assume the directory confirms active upstream health.

The map or rename seems ignored

Overrides outrank map entries. Check name_source and project_file in the registry. If both proxy.yaml and proxy.json exist, choose one using -file before the command. Run CLI commands from a directory without an unrelated map, or select the intended file explicitly. File edits need a reload.

Tailnet links are unavailable

Enable the saved setting with reload --tailnet, rather than ui --tailnet. Check tailscale status and whether the app already has a suitable listener or Serve endpoint. A localhost-only app cannot be reached at the machine’s Tailscale IP just because a link is displayed. Check access rules and firewalls from the other device.

Startup says a port is in use

Inspect ss -ltnp. Give each instance distinct HTTP, HTTPS, admin, and UI ports; keep app ports separate from these. Use high ports for an unprivileged test. The demo script chooses available ports and avoids your normal registry.

The docs preview is not running

python3 scripts/build-docs.py
python3 scripts/serve-docs.py --port 18084

Open http://127.0.0.1:18084. Search loads a local JSON file, so serve the site over HTTP rather than opening HTML directly from disk. No backend API, CDN, font service, or external JavaScript is needed.
